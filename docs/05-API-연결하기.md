# API 연결하기 — 승인받은 다음에 할 일

> 순서대로 따라 하시면 됩니다. 지금은 **1~4단계**까지만 하시면 되고,
> 5단계(수집기 만들기)는 4단계 결과를 보고 이어서 합니다.

---

## 클라우드 환경에서 받기 (PC에 아무것도 설치하지 않는 방법)

Claude Code 웹 세션은 **기본적으로 외부 인터넷이 막혀 있습니다.**
`apis.data.go.kr` 을 허용해주면 Claude가 대신 API를 받아올 수 있습니다.

### 설정 방법

1. [claude.ai/code](https://claude.ai/code) 접속
2. 메시지 입력창 **바로 윗줄**의 **구름 아이콘**을 클릭
   (현재 환경 이름이 적혀 있습니다. 보통 `Default`)
3. 목록에서 환경 이름 위에 마우스를 올리면 오른쪽에 **톱니바퀴 아이콘**이 나옵니다 → 클릭
4. **Network access** 를 `Trusted` → **`Custom`** 으로 변경
5. **Allowed domains** 칸에 한 줄에 하나씩 입력

   ```
   apis.data.go.kr
   www.data.go.kr
   open.mma.go.kr
   www.mma.go.kr
   *.frame.claudeusercontent.com
   ```

   `*.frame.claudeusercontent.com` 은 시제품 화면(Artifact)을 계속 쓰기 위해 필요합니다.

6. **"Also include default list of common package managers"** 를 **체크**
   (체크하지 않으면 위 5개 말고는 전부 막힙니다)
7. **Environment variables** 칸에 인증키를 입력

   ```
   DATA_GO_KR_KEY=여기에_인증키_붙여넣기
   ```

8. 저장

### 중요 — 새 세션을 시작해야 합니다

**설정은 새로 시작하는 세션부터 적용됩니다.** 이미 열려 있는 대화에는 반영되지 않습니다.
저장한 뒤 **새 대화를 시작**하고 이렇게 말하면 됩니다.

> `docs/00-현재상황.md` 를 읽고 이어서 진행해줘. API 수집부터 하면 돼.

### 알아둘 것

- 환경 변수 값은 **그 환경을 쓰는 사람이면 볼 수 있습니다.** 개인 계정이면 본인만 봅니다.
- 인증키를 바꾸거나 지우고 싶으면 같은 화면에서 수정하면 됩니다.
- 저장소에는 키가 올라가지 않습니다 (`.env` 는 `.gitignore` 에 있음).

## (직접 하실 경우) 1단계. 인증키 찾기 (2분)

1. [공공데이터포털](https://www.data.go.kr) 로그인
2. 오른쪽 위 **마이페이지**
3. 왼쪽 메뉴 **데이터활용 → 오픈API → 개발계정**
4. 신청해서 승인된 서비스 이름을 클릭
5. 아래쪽 **일반 인증키** 칸에 긴 문자열이 있습니다

**Encoding / Decoding 두 개가 보입니다.** 어느 쪽을 써야 하는지 헷갈리는 게 정상입니다.
- 겉보기 차이: Encoding 쪽에는 `%2B`, `%3D` 같은 기호가 섞여 있습니다
- 이 프로젝트의 스크립트는 **두 가지를 자동으로 번갈아 시도**하므로,
  아무거나 복사해 넣으시면 됩니다

> **승인 상태 확인**: 같은 화면에 `승인` 이라고 떠 있어야 합니다.
> `신청` 이나 `반려` 면 아직 못 씁니다.
> 개발계정은 보통 자동승인이고 **하루 1만 건**까지 호출할 수 있습니다.

## 2단계. 인증키를 파일에 넣기 (2분)

저장소 최상위에서:

```bash
cp .env.example .env
```

윈도우라면 `.env.example` 파일을 복사해서 이름을 `.env` 로 바꾸면 됩니다.

`.env` 를 메모장으로 열어 이렇게 고칩니다.

```
DATA_GO_KR_KEY=여기에_복사한_인증키_붙여넣기
```

### 꼭 지킬 것 두 가지

**① 인증키는 저장소에 올리면 안 됩니다.**
`.env` 는 `.gitignore` 에 넣어뒀으니 실수로 올라가지 않습니다.
`.env` 안의 키를 다른 파일에 복사해 두지 마세요.

**② 인증키는 화면 코드(HTML/JS)에 절대 넣지 않습니다.**
브라우저에서 누구나 볼 수 있습니다. 키는 **수집 스크립트에서만** 씁니다.

| 모집병 구비서류 | [3066489](https://www.data.go.kr/data/3066489/openapi.do) | 미신청 · 꺼짐 |
| 모집병 군지원 접수현황 | 포털에서 이름으로 검색 | 미신청 · 꺼짐 |

포털의 3066750 페이지에서 **요청주소**를 확인해 주세요.
제가 적어둔 `http://apis.data.go.kr/1300000/mjbJiWon/list` 와 다르면 **포털 쪽이 맞습니다.**
그 주소로 고쳐 넣으세요.

나중에 다른 API를 신청해 승인받으면, 그 API의 `use` 를 `true` 로 바꾸고
`url` 에 요청주소를 넣으면 됩니다.

### 다음으로 신청해두면 좋은 순서

2. **모병합격 배점기준**(3066490) — 배점표를 손으로 옮기지 않아도 될지 확인용
3. 모집병 군지원 접수현황 — 경쟁률
4. 모집병 구비서류

## 4단계. 실제로 무엇이 오는지 확인하기 (1분)

```bash
python3 scripts/probe_api.py
```

이 스크립트는 API를 한 번씩 호출해서

- 응답 원본을 `data/raw/probe/` 에 저장하고
- **응답에 들어있는 항목 이름**을 화면에 보여줍니다

이렇게 나옵니다.

```
[지원가능정보] 모집병 군별 특기별 지원가능 정보
  성공 (URL 디코딩한 키, 형식 json)  → 저장: data/raw/probe/지원가능정보.json
  응답 항목 9개:
     - gunGbcd                 예: 1
     - tgCd                    예: 162104
     - tgNm                    예: 전기설비
     ...
```

**이 목록을 그대로 복사해서 알려주세요.** 그러면 그 이름에 맞춘 수집 스크립트를 만들어 드립니다.

### 실패하면

| 화면에 나오는 말 | 원인 | 할 일 |
|---|---|---|
| `SERVICE_KEY_IS_NOT_REGISTERED` | 승인 안 됨 / 키가 다름 | 마이페이지에서 승인 상태와 키 재확인 |
| `HTTP 403`, `HTTP 404` | 요청주소가 틀림 | 포털의 요청주소를 다시 복사 |
| `LIMITED_NUMBER_OF_SERVICE_REQUESTS` | 하루 한도 초과 | 다음 날 다시 시도 |
| `주소없음` | `url` 이 비어 있음 | 3단계로 |

**승인 직후에는 1~2시간 정도 반영이 늦을 수 있습니다.** 바로 실패하면 조금 뒤 다시 해보세요.

## 5단계. 실제로 받아오기 — 준비 완료

`scripts/collect_jiwon.py` 가 '지원가능 정보' API를 받아옵니다.

### 먼저 조금만 받아보기 (1분)

```bash
python3 scripts/collect_jiwon.py --pages 5
```

5페이지(5,000건)만 받아 잘 도는지 확인합니다. 이렇게 나오면 성공입니다.

```
전체 1,371,302건 · 한 번에 1000건 · 총 1,372페이지
자격 등급 종류:
   '기사급이상'  12,345건
   ...
```

### 전체 받기 (약 30분, 켜두고 다른 일 하세요)

```bash
python3 scripts/collect_jiwon.py
```

- 중간에 끊겨도 **다시 실행하면 이어서** 받습니다
- 이미 받은 페이지는 건너뜁니다
- 하루 한도(1만 건)의 약 14%만 씁니다

### 받은 뒤 생기는 파일

| 파일 | 내용 |
|---|---|
| `data/build/jiwon.sqlite` | 받은 원본 창고 (중복 자동 제거) |
| `data/build/major_index.json` | 학과명 → 이 학과를 인정하는 특기 목록 |
| `data/build/cert_index.json` | 자격명 → 이 자격을 인정하는 특기·등급 |
| `data/build/jiwon_stats.json` | 특기별 인정 전공/자격 개수 |
| `data/build/_jiwon_report.json` | 등급·군·지침 등 실제 값 목록 |

### 다 받은 뒤 알려주실 것

화면 끝에 **자격 등급 종류**가 나옵니다. (`기사급이상`, `산업기사급` 같은 것들)

**그 목록을 그대로 알려주세요.** 배점표(`rules/2026-army-tech.json`)의 점수와
실제 등급 이름을 연결해야 점수 계산이 맞습니다.

커트라인 CSV를 붙이면 시제품이 실제 데이터로 동작합니다.

## 참고 — 호출 예의

- 전체 재수집은 **하루 1회**면 충분합니다. 모집기간 중 접수현황만 자주 부르세요.
- 호출 사이에 잠깐씩 쉬도록 스크립트에 간격을 넣습니다.
- 인증키는 **1인 1개**이고 양도할 수 없습니다. 담당자가 바뀌면 새로 신청해야 합니다.
