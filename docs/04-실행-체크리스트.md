- [x] 공공데이터포털 회원가입
- [x] 오픈API 활용신청 · 승인 완료
- [ ] `.env` 에 인증키 넣기 (→ [05번 문서](05-API-연결하기.md))
- [ ] `config/endpoints.json` 의 빈 요청주소 채우기
- [ ] `python3 scripts/probe_api.py` 실행 → 응답 항목 이름 확인
- [ ] 배점기준 API(3066490·3066491)가 배점표를 주는지 확인
- [ ] 커트라인 CSV 3종 내려받아 **엑셀로 직접 열어보기**
- [ ] 특기명이 API와 CSV에서 같은지 눈으로 대조 (다르면 목록으로 정리)
- [ ] 병무청 평가요소·배점기준 페이지 인쇄

## 1~2주차 — 데이터 창고
- [ ] `scripts/collect.py` 작성 — API 호출 → `data/raw/`에 원본 저장
- [ ] 커트라인 CSV 읽기 (인코딩 `cp949` 주의) → 표준 형식 변환
- [ ] `specialty_alias` 별칭 사전 작성 (특기명 통일)
- [ ] `data/build/` 에 표준 JSON 5종 생성
- [ ] **검증**: 특기 하나를 골라 API 정보와 커트라인이 같이 나오는지 확인

## 3주차 — 점수 계산기
- [ ] `rules/2026-army-tech.json` 배점표 작성 (`source`, `checked_at` 포함)
- [ ] 계산 함수 작성 — 입력 → `total` + `breakdown` 반환
- [ ] **검증**: 작년 합격 사례 3건으로 점수 확인

## 4주차 — 추천 엔진
- [ ] 자격/전공 → 특기 후보 추출
- [ ] 흥미유형 매핑표(`interest_map.json`) 초안 — 상담사 자문
- [ ] 가중치 합산 → 정렬 → ① 유력 / ② 근접 / ③ 도전 3구간 분류

## 5~6주차 — 화면
- [ ] ① 입력 화면 (문항 최소화, 흥미유형은 건너뛰기 가능)
- [ ] ② 추천 특기 카드 목록
- [ ] ③ 특기 상세 — **3년 커트라인 꺾은선 + 내 점수 가로선**
- [ ] ④ 갭 분석 — 항목별 막대 + "이걸 하면 +N점"
- [ ] 모든 화면 하단에 "참고용 추정치" 고지 문구
- [ ] 인쇄/PDF 저장 (상담 후 청년에게 종이로 주기)

## 공개 전 최종 점검
- [ ] 인증키가 화면 코드(HTML/JS)에 노출되지 않았는가
- [ ] 개인정보를 저장하지 않는가 (익명 입력·세션 종료 시 삭제)
- [ ] "합격한다" 같은 단정 표현이 없는가
- [ ] 기준연도가 모든 점수 화면에 표시되는가
- [ ] 상담사 2명 이상이 실제 사례로 시연해봤는가

## 운영 (계속)
