# 데이터 지도 — 무엇을 어디서 가져오는가

## 한눈에 보기

```
                    ┌──────────────────────────────┐
  병무청 오픈API ───▶│                              │
  (실시간 조회)      │      scripts/collect.py      │
                    │   (하루 1회 또는 수동 실행)    │──▶ data/build/*.json ──▶ 상담 화면
  커트라인 CSV ─────▶│                              │
  (연 1~2회 갱신)    │  · 이름 통일  · 코드 붙이기    │
                    │  · 3년치 합치기               │
  배점표 규칙 ──────▶│                              │
  (사람이 입력)      └──────────────────────────────┘
```

## 1. 오픈API (data.go.kr에서 활용신청 필요)

| 데이터 | 쓰는 곳 | 링크 |
|---|---|---|
| 모집병 군사특기 정보 | 특기 목록, 임무·신체조건·면접여부 | https://www.data.go.kr/data/3066488/openapi.do |
| 모집병 군별 특기별 지원가능 정보 | **자격/면허·전공 → 특기 매칭** | https://www.data.go.kr/data/3066750/openapi.do |
| 모집병 구비서류 | 특기 상세의 준비물 안내 | https://www.data.go.kr/data/3066489/openapi.do |
| 모집병 군지원 접수현황 | 경쟁률 | data.go.kr에서 "모집병 군지원 접수현황" 검색 |
| 맞춤형 특기병 정보 | 선발인원 | https://www.data.go.kr/data/15017227/openapi.do |
| 국가자격 종목 목록 (산업인력공단) | 자격증 이름 자동완성·등급 판별 | https://www.data.go.kr/data/15003024/openapi.do |

공통 요청 형태 (예시)

```
GET {엔드포인트}?serviceKey={인증키}&numOfRows=100&pageNo=1&gunGbcd=1&mojipGbcd=1
```

- 군구분(`gunGbcd`): 육군/해군/공군/해병대
- 모집분야(`mojipGbcd`): 기술행정병 / 일반·전문기술병 / 전문특기병 등
- **정확한 변수명은 활용신청 후 받는 "활용가이드(참고문서)"에 있습니다.** 반드시 그 문서를 기준으로 하세요.

### 수집 시 지켜야 할 3가지
1. **원본 응답을 그대로 `data/raw/`에 날짜별로 저장**해두기 (나중에 문제 생기면 여기서 확인)
2. 트래픽 제한이 있으므로 **전체 재수집은 하루 1회**로 충분
3. 실패해도 이전 데이터로 계속 동작하게 (상담 중 화면이 비면 안 됨)

## 2. 커트라인 파일데이터 (CSV 내려받기)

| 데이터 | 링크 |
|---|---|
| 육군 기술행정병 1차합격 커트라인 | https://www.data.go.kr/data/15130030/fileData.do |
| 공군병 모집직종별 1차 선발 커트라인·선발인원 | https://www.data.go.kr/data/15129915/fileData.do |
| 해병대병 모집직종별 1차 선발 커트라인·선발인원 | https://www.data.go.kr/data/15139177/fileData.do |

- **최근 3년치**를 제공하므로 "3년 비교" 요구사항과 정확히 맞습니다.
- 파일명에 기준일자가 붙습니다(예: `_20241031`). 받은 파일은 **이름 그대로** `data/raw/cutoff/`에 보관하세요.
- 인코딩이 EUC-KR인 경우가 많습니다. 파이썬에서 `encoding='cp949'`로 읽으세요.

### 커트라인 표준화 규칙
원본 열 이름이 자료마다 달라도 아래 형태로 바꿔서 저장합니다.

```json
{
  "year": 2024, "round": 11, "branch": "육군",
  "specialty_code": "A0123", "specialty_name_raw": "일반의무",
  "cutoff_score": 72.5, "selected_count": 34, "unit": "○○사단"
}
```

`specialty_name_raw`(원본 이름)를 **꼭 같이 남겨두세요.** 코드 연결이 틀렸을 때 추적할 수 있습니다.

## 3. 직업흥미유형

- 워크넷 심리검사결과 API는 **학교코드·학번**이 필요하고, 비회원 결과는 **7일 뒤 삭제**됩니다.
  → 상담도구에서 자동 연동은 권하지 않습니다.
- 대신 **화면에서 유형을 직접 고르게** 하세요. (예: 현실형 R / 탐구형 I / 예술형 A / 사회형 S / 진취형 E / 관습형 C)
- 이미 워크넷 검사를 받았다면 결과지의 유형을 보고 고르면 됩니다.
- 특기 ↔ 흥미유형 연결표는 **상담사가 직접 만드는 자산**입니다. 예:

```json
{ "정비": ["R", "C"], "조리": ["R", "S"], "전산": ["I", "C"], "군악": ["A"] }
```

## 4. 갱신 주기 달력

| 데이터 | 갱신 | 담당 |
|---|---|---|
| 특기·지원가능 정보 | 매일 자동 | 스크립트 |
| 접수현황 | 모집기간 중 매일 | 스크립트 |
| 커트라인 CSV | **연 1~2회 수동 확인** | 담당자 |
| 배점표 규칙 | **모집계획 공고 시 확인** | 담당자 |

수동 항목 2개를 놓치면 도구가 조용히 낡습니다. 달력 알림을 꼭 걸어두세요.
