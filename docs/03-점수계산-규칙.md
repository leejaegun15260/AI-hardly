# 점수 계산 규칙 — 배점표를 코드로 옮기기

> 기준: 육군 기술행정병 (연도별로 개정되므로 **반드시 최신 공고를 확인**하고 숫자를 갱신하세요)
> 출처: https://www.mma.go.kr/contents.do?mc=mma0000387
>
> **먼저 확인할 것**: `모병합격 배점기준` API(3066490)와 `모병 개별특기 배점구분` API(3066491)가
> 있습니다. 이 API가 배점표를 충분히 주면 아래 표를 손으로 옮길 필요가 없어집니다.
> `python3 scripts/probe_api.py` 로 먼저 확인하세요. → [05번 문서](05-API-연결하기.md)

## 1. 총점 구조

```
자격/면허 50  +  전공 40  +  출결 10  +  가산점 15   =  최대 115점
(2차 전형은 면접 적·부 판정)
```

## 3. 계산 결과 형식 — 총점만 주지 말 것

상담에서 쓰려면 **왜 그 점수인지**가 같이 나와야 합니다.

```json
{
  "total": 82,
  "max_total": 115,
  "breakdown": [
    { "name": "자격/면허", "score": 40, "max": 50, "gap": 10,
      "reason": "기능사(전기기능사) 보유",
      "advice": "산업기사 취득 시 45점 (+5)" },
    { "name": "전공",     "score": 32, "max": 40, "gap": 8,
      "reason": "전문대 전기과 (관련학과)" },
    { "name": "출결",     "score": 10, "max": 10, "gap": 0,
      "reason": "무단결석 없음" },
    { "name": "가산점",   "score": 0,  "max": 15, "gap": 15,
      "reason": "해당 항목 없음",
      "advice": "직업선호도 검사 후 추천특기와 일치 시 가산점 대상" }
  ]
}
```

이 `breakdown` 배열이 그대로
- 화면 ④의 **막대그래프**(score vs max)
- 화면 ④의 **처방 목록**(advice)
이 됩니다. 즉 **계산기 하나만 잘 만들면 화면 두 개가 따라옵니다.**

## 4. 커트라인 비교 로직

```
여유점수 = 내 예상점수 − 최근 3년 같은 회차 커트라인의 대표값
```

- 대표값은 **최근 3년 평균**과 **가장 높았던 해**를 둘 다 보여주세요.
  (평균만 보면 방심하고, 최고만 보면 포기합니다)
- 판정 문구 예시 (단정 표현 금지)

| 여유점수 | 표시 |
|---|---|
| +5점 이상 | 여유 있는 편 |
| 0 ~ +5점 | 경계선 — 가산점 확보 권장 |
| −5 ~ 0점 | 부족 — 보완 필요 |
| −5점 미만 | 다른 특기 병행 검토 권장 |

**주의**: 커트라인은 회차·입영부대별로 다릅니다.
반드시 **같은 회차(월)끼리** 비교하고, 화면에 "○년 ○회차 기준"을 표시하세요.

## 5. 검증 방법

만들고 나면 꼭 이 절차로 확인하세요.

1. 작년 실제 합격 사례 3~5건의 조건을 입력
2. 계산된 점수가 그해 커트라인 **이상**으로 나오는지 확인
3. 어긋나면 배점표 해석이 틀린 것 → 공고 원문 재확인

이 검증을 통과하기 전에는 상담 현장에 내보내지 마세요.
