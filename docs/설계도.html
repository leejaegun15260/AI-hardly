설계 제안 · Design Brief

병역진로설계 상담도구

전공 · 자격/면허 · 직업흥미유형을 넣으면 어울리는 군사특기를 찾아주고, 지금 내 점수를 계산해 최근 3년 커트라인과 비교한 뒤, 무엇을 더 갖춰야 하는지 알려주는 상담 화면. 만드는 순서와 준비물을 정리했습니다.

대상 병역대기자 · 상담 창구 재료 병무청 공공데이터 기간 6주 (MVP) 2026.09
01

이 도구가 답하는 네 가지 질문

청년이 상담석에 앉아 던지는 질문은 늘 이 넷입니다. 이 넷이 곧 화면 네 개이고, 만드는 순서도 이 순서입니다. 앞의 것이 없으면 뒤의 것을 만들 수 없습니다.

탐색

제 전공으로 갈 수 있는 특기가 뭐예요?

특기 추천

자격·전공·흥미유형에 맞는 특기를 골라 순위를 매깁니다.

이해

그 특기는 무슨 일을 하나요?

특기 소개

임무·신체조건·면접 여부·구비서류를 한 장에 보여줍니다.

진단

저는 지금 몇 점인가요?

점수 계산

배점표대로 항목별 점수와 그 이유를 함께 냅니다.

처방

갭 분석

02

가장 먼저 알아야 할 것 — 데이터는 세 종류다

“공공API를 쓰면 다 해결되겠지”가 첫 번째 함정입니다. 커트라인은 API가 아니라 내려받는 엑셀 파일이고, 점수 배점표는 아예 데이터로 제공되지 않습니다. 이 셋을 다르게 다뤄야 합니다.

가 · 실시간 API

부르면 바로 오는 것

  • 모집병 군사특기 정보
  • 군별·특기별 지원가능 정보 ← 추천의 심장
  • 모집병 구비서류
  • 군지원 접수현황 (경쟁률)
자동 수집 · 하루 1회면 충분
나 · 파일(CSV)

받아서 쌓아두는 것

  • 육군 기술행정병 1차 합격 커트라인
  • 공군병 직종별 1차 선발 커트라인
  • 해병대병 직종별 1차 선발 커트라인
연 1~2회 수동 · 최근 3년치 제공
다 · 사람이 입력

데이터가 없는 것

  • 평가요소 및 배점기준 (자격 50 · 전공 40 · 출결 10 · 가산점 15)
  • 특기 ↔ 직업흥미유형 연결표
공고 개정 시 확인 · 연도별 파일로 관리

그림 1 — 인증키는 왼쪽 ‘수집·정리’ 단계에서만 씁니다. 화면 코드에 키를 넣으면 그대로 노출됩니다.

03

만드는 순서

순서를 지키는 것이 요령입니다. 특히 0단계를 건너뛰고 코드부터 짜면 거의 확실하게 다시 만들게 됩니다.

  1. 0

    준비 약 3일 — 대부분 기다리는 시간

    • 공공데이터포털 가입 → API 활용신청 (운영계정 승인 1~2일)
    • 커트라인 CSV를 내려받아 엑셀로 직접 열어보기
    • API의 특기명과 CSV의 특기명이 글자까지 같은지 대조
    철칙: 데이터 실물을 눈으로 본 뒤에 설계합니다. 신청해두고 기다리는 동안 배점표를 옮겨 적으면 시간이 절약됩니다.
  2. 1

    데이터 창고 만들기 1~2주 — 전체에서 가장 중요

    출처가 제각각인 자료를 우리만의 표 다섯 개로 정리합니다. 특기 / 특기–자격 / 특기–전공 / 커트라인 이력 / 지원자 수.

    여기서 성패가 갈립니다. CSV의 “일반의무”와 API의 “일반의무병”이 다른 이름으로 취급되면, 추천은 되는데 커트라인이 안 뜨는 도구가 됩니다. 별칭 사전을 두고 모든 자료를 특기코드 하나로 묶으세요.
  3. 2

    점수 계산기 1주

    배점표를 연도별 규칙 파일로 옮깁니다. 숫자를 코드에 박아넣지 말고 파일에 두면, 기준이 개정돼도 파일만 갈아끼우면 됩니다.

    총점만 주지 마세요. “자격/면허 40점 — 기능사 보유, 만점 50점”처럼 항목마다 이유를 함께 내야 상담이 됩니다. 이 항목별 결과가 그대로 ④번 화면의 재료가 됩니다.
  4. 3

    특기 추천 엔진 1주

    자격 40% · 전공 30% · 흥미유형 20% · 합격 가능성 10%로 후보에 점수를 매겨 정렬하고, 지금도 유력 / 조금만 더 / 도전 세 묶음으로 보여줍니다.

    흥미유형 연결표는 공공데이터에 없습니다. 상담사 경험으로 만든 엑셀 한 장이 이 도구의 진짜 차별점이 됩니다.
  5. 4

    화면 만들기 2주

    입력은 3~4문항으로 끝나게 하고, 설득력은 ③·④번 화면에 몰아줍니다. 상담 후 종이로 뽑아 줄 수 있게 인쇄용 화면도 함께.

  6. 5

    검증과 운영 계속

    • 작년 실제 합격 사례 3~5건을 넣어 계산 결과가 맞는지 확인
    • 커트라인 CSV 갱신 · 배점 개정 시기를 달력에 알림 등록
    • 모든 화면에 “참고용 추정치” 고지 상시 노출
04

핵심 화면 미리보기

청년을 가장 잘 설득하는 그림은 이 둘입니다. 왼쪽은 “내가 지금 어디쯤인지”, 오른쪽은 “뭘 하면 되는지”를 보여줍니다.

그림 2 — 커트라인은 회차·입영부대별로 다릅니다. 반드시 같은 회차끼리 비교하고, 화면에 기준 회차를 적어두세요.

05

미리 알아둘 함정 다섯

함정대응
자료마다 특기명이 조금씩 다르다별칭 사전을 두고 모든 자료를 특기코드 하나로 묶습니다.
커트라인이 회차·입영부대별로 쪼개져 있다비교 기준을 “같은 회차끼리”로 못 박고 화면에 명시합니다.
배점 기준이 해마다 개정된다규칙 파일을 연도별로 분리하고, 화면에 기준연도를 표시합니다.
흥미검사 결과 API는 학번·학교코드가 필요하고 비회원 결과는 7일 뒤 삭제된다자동 연동 대신 화면에서 유형을 직접 고르게 하고, 개인정보는 저장하지 않습니다.
“합격한다”고 오해한다모든 수치에 ‘추정’을 표기하고 단정 표현을 쓰지 않습니다.
