# 새 API 붙이기 — 승인받은 다음 따라 하기

> 활용신청이 **승인된 뒤**에 하는 일입니다.
> 인증키는 이미 넣어 두었으니(`.env`), **요청주소 하나만 찾아오면** 됩니다.
> 마지막 갱신: 2026-09-16

---

## 먼저 알아둘 것 — 막히는 건 거의 '요청주소' 하나입니다

공공데이터포털에는 주소가 **두 가지**인데 서로 다릅니다.

| | 예 | 쓰는 곳 |
|---|---|---|
| **화면 주소** (브라우저 주소창) | `https://www.data.go.kr/data/3066490/openapi.do` | 사람이 보는 페이지 |
| **요청주소** (진짜 필요한 것) | `http://apis.data.go.kr/1300000/____/list` | 프로그램이 부르는 주소 |

화면 주소를 넣으면 절대 안 됩니다.
**요청주소는 추측하면 안 됩니다.** 실제로 `bjGiJun`, `baejeom` 등 그럴듯한 이름을
여덟 가지 넣어 봤지만 전부 "해당 오픈API 서비스가 없거나 폐기됨"이 났습니다.

---

## 가장 빠른 길 — 활용가이드 파일을 그냥 보내주세요

포털 API 페이지의 **[참고문서]** 에 있는 **활용가이드**(한글 `.hwp`·워드·PDF)를
내려받아 이 대화에 **그대로 올려 주시면** 제가 열어서
요청주소 · 요청 항목 · 응답 항목을 뽑아 정리하겠습니다.
페이지에서 눈으로 찾는 것보다 확실하고 빠릅니다.

직접 찾아보고 싶으시면 아래 1단계부터 하시면 됩니다.

---

## 1단계. 요청주소 찾기 (3분)

1. 공공데이터포털에 로그인
2. **마이페이지 → 개발계정** → 승인된 API 이름 클릭
   (또는 그 API의 화면 주소로 바로 이동)
3. 페이지에서 **요청주소**를 찾습니다. 보통 이 세 군데 중 하나에 있습니다.
   - 페이지 가운데 **[End Point]** 또는 **[요청주소]** 라고 적힌 칸
   - **[상세설명]** 탭 안
   - **[참고문서]** 의 **활용가이드** 파일(한글·PDF)을 내려받아 열면 맨 앞쪽
4. `http://apis.data.go.kr/...` 로 시작하는 줄을 **끝까지 그대로** 복사합니다.

> 활용가이드 문서 안에는 상세기능이 여러 개일 수 있습니다
> (예: `목록조회`, `상세조회`). 우리가 쓸 것은 보통 **목록조회**입니다.
> 주소 끝이 `/list`, `/getList` 처럼 기능마다 다릅니다. 그 끝까지 복사하세요.

---

## 2단계. 주소가 진짜 되는지 확인 (30초)

터미널에 이렇게 칩니다. **따옴표로 감싸세요.**

```bash
python3 scripts/check_api.py "여기에 복사한 요청주소 붙여넣기"
```

- 파일을 고칠 필요 없습니다. 주소만 넣으면 됩니다.
- 인증키는 이미 들어 있어서 따로 넣지 않습니다.
- 인증키의 두 가지 형태(Encoding·Decoding)와 JSON·XML을 **알아서 번갈아** 시도합니다.

### 잘 됐을 때

```
[JSON · 인증키 그대로] 성공 ✅

   전체 건수: 1234
   받은 줄: 3개

   항목 이름                값 (첫 줄)
   ------------------------------------------------------------
   gunGbcd                1
   gsteukgiCd             121.101
   ...
```

여기 나온 **항목 이름 목록이 곧 설계도**입니다. 이대로 알려주시면 수집기를 만들어 드립니다.

### 안 됐을 때 — 화면에 원인이 쉬운 말로 나옵니다

| 화면에 나오는 말 | 뜻 | 할 일 |
|---|---|---|
| 주소가 틀렸습니다 | 그런 API가 없음 | 1단계로 돌아가 주소를 다시 복사 |
| 인증키가 이 API에 등록되어 있지 않습니다 | 주소는 맞음 | 승인 직후면 몇 분~1시간 기다렸다 다시 |
| 이 API를 쓸 권한이 없습니다 | 승인 안 됨 | 마이페이지에서 '승인' 인지 확인 |
| 자료를 주는 쪽(병무청) 서버가 응답하지 않습니다 | 우리 잘못 아님 | 시간을 두고 다시 |
| 오늘 쓸 수 있는 횟수를 다 썼습니다 | 하루 1만 건 초과 | 내일 다시 |

## 3단계. 주소를 저장소에 적기 (1분)

성공한 뒤에만 합니다. `config/endpoints.json` 을 열어 해당 API를 찾아
**두 곳**을 고칩니다.

```json
{
  "name": "배점기준",
  "url": "여기에 성공한 주소",
  "use": true
}
```

- `url` — 성공한 주소를 그대로
- `use` — `false` 를 `true` 로

---

## 4단계. 알려주시면 됩니다

2단계에서 나온 **항목 이름 목록**을 그대로 붙여넣어 알려주세요.
그 자료를 받아서 화면에 붙이는 프로그램은 제가 만들겠습니다.

전체를 받아오는 것은 자료 양에 따라 다릅니다
(지원가능정보는 136만 건이라 40분 걸렸습니다).

## 왜 배점기준 API가 중요한가

지금 배점표(`rules/2026-army-tech.json`)에는 **확인 전(`confirmed: false`)** 인 값이 남아 있습니다.

- 기술행정병: 전공 점수 구간, 가산점 항목별 점수
- 운전: 총점, 운전면허 점수(90 / 87)

배점기준 API가 이 값들을 직접 주면, 공고를 손으로 옮기지 않아도 됩니다.
**항목 이름만 알려주시면** 배점표를 자동으로 만들어 넣는 프로그램을 만들겠습니다.
