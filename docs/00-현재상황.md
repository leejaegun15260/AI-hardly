## 지금 막혀 있는 것

**클라우드 세션에서 `apis.data.go.kr` 접속이 차단**되어 API를 받아올 수 없습니다.

해결: 환경 설정에서 **Network access = Custom** 으로 바꾸고 도메인을 허용하면 됩니다.
방법은 [05번 문서](05-API-연결하기.md)의 '클라우드 환경에서 받기' 절에 있습니다.

## 다음에 할 일 (순서대로)

1. **환경 설정 변경 후 새 세션 시작** → 아래 명령 실행
   ```bash
   python3 scripts/collect_jiwon.py --pages 5     # 시험
   python3 scripts/collect_jiwon.py               # 전체 (약 30분)
   ```
2. 실행 결과의 **자격 등급 목록**(`기사급이상` 등)을 배점표와 연결
   → `rules/2026-army-tech.json` 에 `grade_alias` 추가
3. 화면(`web/index.html`)이 샘플 대신 **실제 자격/전공 색인**을 쓰도록 교체
   - 지금: `specialty_cert.json` / `specialty_major.json` (샘플, 13개 특기)
   - 바꿀 것: `cert_index.json` / `major_index.json` (실제, 137만 건에서 뽑은 색인)
4. 커트라인 CSV 붙이기 (인터넷 없이 파일만 올리면 됨)
5. 남은 API 신청 — 군사특기 정보(3066488) → 배점기준(3066490) → 접수현황 → 구비서류

## 아직 결정하지 못한 것

**예술형·사회형 특기가 각각 3개뿐입니다.**
이 유형이 나온 청년에게 3개만 보여주면 상담이 막힙니다.
인접 유형(예: 사회형 → 진취형·관습형)을 함께 보여줄지, 보여준다면 어떻게 표시할지
**상담 정책 결정이 필요**합니다. 결정되면 화면에 반영합니다.
