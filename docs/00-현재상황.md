### 받으면서 걸린 것 세 가지 (다음 API 때도 똑같이 겪습니다)

**1) 포털 문서의 `http` 주소는 막힙니다.** 프록시를 거치는 환경(클라우드·회사망)에서
`http://apis.data.go.kr/...` 은 403 이 납니다. **`https` 로만 바꾸면** 같은 주소로 그대로 됩니다.

**2) 특기코드 끝의 0 이 달랐습니다.** 엑셀은 코드가 숫자로 저장돼 `163.110` 이 `163.11` 로
줄어 있고, API 는 원래 코드를 줍니다. 문자열로 비교하면 그런 특기는 자격·전공이
**하나도 연결되지 않은 채 조용히 빈칸으로 남습니다.** 지금은 수집기가 양쪽을 맞춥니다.

**3) 연결이 자주 끊깁니다.** `Connection reset by peer` 가 수시로 납니다.
지금은 못 받은 페이지만 모아 다시 훑고, 그래도 남으면 다음 실행 때 이어받습니다.

## 아직 결정하지 못한 것

**예술형·사회형 특기가 각각 3개뿐입니다.**
이 유형이 나온 청년에게 3개만 보여주면 상담이 막힙니다.
인접 유형(예: 사회형 → 진취형·관습형)을 함께 보여줄지, 보여준다면 어떻게 표시할지
**상담 정책 결정이 필요**합니다. 결정되면 화면에 반영합니다.

## 알아둘 것

- **간접 인정의 점수 차이를 모릅니다.** API 는 자격·전공을 `직접`/`간접` 으로 나눠 주는데
  (간접이 30만 건), 공고에서 점수 차이가 확인되지 않아 지금은 **똑같이 계산**합니다.
  배점기준 API 나 공고에서 확인되면 `rules/2026-army-tech.json` 에 반영해야 합니다.
- 배점표의 **전공·출결 점수 구간은 아직 예시값**입니다 (`confirmed: false`).
  화면에도 확인 전 항목으로 표시됩니다.
