# 병역진로설계 상담도구 (Military Career Design Counseling Tool)

병역대기자(입영 전 청년)가 **전공 · 자격/면허 · 직업흥미유형**을 입력하면
→ 어울리는 **군사특기를 추천**받고
→ 그 특기의 **역할·근무환경·구비서류**를 확인하고
→ 지금 상태로 **본인 점수를 계산**해보고
→ **최근 3년 커트라인과 비교**해서
→ **무엇을 더 갖춰야 하는지** 알려주는 상담 도구입니다.

상담 창구에서 상담사가 화면을 같이 보며 설명하는 용도를 1순위로 설계합니다.

## 시제품 실행하기

**방법 1 — 파일 하나만 열기 (제일 쉬움)**

`docs/시제품.html` 을 더블클릭하면 바로 열립니다. 데이터가 파일 안에 들어 있습니다.

**방법 2 — 개발용 (데이터를 고쳐가며 볼 때)**

```bash
python3 scripts/import_interest_xlsx.py   # 실제 자료: 흥미유형별 군사특기 엑셀 → JSON
python3 scripts/make_sample_data.py       # 샘플: 자격/전공/커트라인
python3 -m http.server 8000               # 저장소 최상위에서 실행
# 브라우저에서 http://localhost:8000/web/ 열기
```

데이터나 배점을 고친 뒤 단일 파일을 다시 만들려면:

```bash
python3 scripts/build_single_file.py    # → docs/시제품.html 갱신
```

## 폴더 구조

```
data/raw/     # 공공데이터포털에서 받은 원본 (CSV/JSON) — 손대지 않음
data/build/   # 앱이 실제로 읽는 표준 데이터 (지금은 샘플)
rules/        # 연도별 배점표 규칙 파일
scripts/      # 데이터 생성·가공 스크립트
web/          # 상담 화면 (개발용)
docs/         # 설계 문서 + 단일 파일 시제품
```

## 지금 상태

| 항목 | 상태 |
|---|---|
| 화면 4개 (입력 · 추천 · 커트라인 · 갭 분석) | 동작함 |
| 점수 계산 · 커트라인 비교 · 개선 시뮬레이션 | 동작함 |
| **군사특기 목록 212개 (육·해·공·해병)** | **실제 자료** |
| **직업흥미유형 ↔ 특기 연결, 직업군 65종** | **실제 자료** |
| 특기별 인정 자격/전공 | API 승인 완료 · 수집기 준비됨 (`scripts/collect_jiwon.py`) |
| 커트라인·지원자 수 | 샘플 — 13개 특기만 |
| 배점표 | 자격/면허·가산점만 공고 확인, 나머지는 예시값 |

**다음 할 일**: `scripts/make_sample_data.py` 를 `scripts/collect.py` 로 바꿔
실제 공공API와 커트라인 CSV를 읽게 만들면, 화면은 그대로 두고 진짜 데이터로 동작합니다.
특기 목록과 흥미유형은 이미 실제 자료이므로 손댈 필요가 없습니다.

## 중요 고지

이 도구의 계산 결과는 **참고용 추정치**입니다. 실제 선발 점수와 합격 여부는
병무청 및 각 군의 공식 기준과 심사 결과에 따릅니다.
